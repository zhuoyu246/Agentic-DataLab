# Frontend

Vue 3 operational workspace for Agentic DataLab.

## Run

```bash
npm install
npm run dev
```

The Vite dev server proxies `/api` to `http://127.0.0.1:8000`.

## Screens

- left sidebar: upload, tenant/model/security settings, dataset selector
- chat panel: supervisor interaction
- pipeline graph: Vue Flow lineage graph
- artifact panel: EDA/SQL/chart/model payloads
- run timeline: SSE events from backend
